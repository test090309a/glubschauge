📋 Folgeprompt für einen Agenten – glubschauge

Du übernimmst die Weiterentwicklung eines Python-Projekts namens glubschauge – ein TUI-basierter Netzwerk-Monitor mit lokaler KI. Hier ist der komplette Zustand.
1. Projektziel

Ein dauerhaft laufendes Monitoring-Tool für ein Heimnetzwerk auf Windows 11, das:

    Netzwerkverkehr live via tshark mitschneidet

    Regelbasierte Detektoren auf die Pakete anwendet

    Erkannte Events an ein lokales LLM (Ollama) zur Bewertung übergibt

    Die Ergebnisse in einer Textual-TUI anzeigt

    Eine Dash-Weboberfläche als grafisches Dashboard bereitstellt

    Optional: Wireshark-Sprung bei Events (Ringpuffer), Markdown-Export

Motivation des Nutzers: Privatsphäre – kein Cloud-LLM, alles lokal. Perspektivisch möchte der Nutzer "professionelle" Netzwerküberwachung im Heimnetz.

8. Kritische Lessons Learned (Fallstricke)

Diese Fehler sind bereits aufgetreten – ein neuer Agent sollte sie kennen:
8.1 tshark-spezifisch

    -T ek liefert 2 Zeilen pro Paket: Erst Index-Header, dann Paket-JSON. Der Parser muss Index-Header ignorieren (if "index" in obj).

    TCP-Flags: tshark 4.6 liefert boolesche Felder (tcp_tcp_flags_syn, tcp_tcp_flags_reset, tcp_tcp_flags_push – nicht _rst/_psh). Der Parser muss diese zuerst probieren, dann erst tcp_tcp_flags_str (das ist bei tshark 4.6 ASCII-Art wie ·······A···· und nutzlos).

    -l ist Pflicht für Live-Ausgabe, sonst puffert tshark minutenlang.

    Interface per Index statt Name ansprechen (-i 8), weil Namen Sonderzeichen enthalten können.

8.2 Python/asyncio

    asyncio.create_task() in einer async def die via run_until_complete aufgerufen wird: Tasks werden gecancelt, wenn der Loop endet. Lösung: Alle Tasks im on_mount() der Textual-App starten.

    Textual run_worker(..., exclusive=True) killt alle anderen Worker derselben Gruppe – nicht ohne group= verwenden.

    self.run_worker(self._foo(), ...) muss aufgerufen werden (Klammern), nicht als Methodenreferenz übergeben.

8.3 Textual

    add_columns("a", "b") + self.columns["a"].width funktioniert nicht in allen Versionen. Stattdessen add_column("a", width=…).

    cursor_row liefert Index, nicht RowKey. Aktuellen Event per on_data_table_row_highlighted tracken.

    update_cell(row_key, column_key, ...) braucht die echte ColumnKey (Rückgabe von add_column).

8.4 SQLite

    Schema-Updates: Beim Einfügen neuer CREATE TABLE-Statements in SCHEMA kann ein Fehler mittendrin den Rest verschlucken (deshalb fehlte hosts). Nach Schema-Änderungen immer glubschauge.db löschen.

    Foreign Keys wurden entfernt – waren die Ursache.
